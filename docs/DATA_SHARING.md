# Sharing data

The public example contains synthetic data only. Keep research inputs and outputs private unless the data owner approves sharing them.

The default `data/raw/`, `figures/`, `results/`, and generated research report are ignored by Git. An output directory supplied with `--output` may not be ignored: check before committing. Sample pseudonyms do not prevent all re-identification.

Only use `--synthetic` for generated example data. That flag labels outputs; it does not sanitize research data.
